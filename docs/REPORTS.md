# Source-bound fixture reports

`source-bound-reports-v2` renders archived fields, not a newly fitted or recomputed research run.
Candidate memos include model/as-of scope, primary source references, acceptance/publication times,
and the later clock plus declared processing lag. Future or nonfinite evidence rejects; legacy
missing filing clocks remain unavailable. Static artifacts do not guess a reading-time data age.
Fixture URI references identify synthetic evidence and are not real primary filings.

Historical cases use independently archived study-anchor features, never the current signal as a
substitute. Available anchor prices/technical/financial fields and dated filing citations are
separate from later outcome multiples, terminal returns and drawdowns. Missing anchor profiles
stay unavailable. Matching seeds, strata/probability/weight and sector-proxy scope remain visible.
No causal customer/contract/catalyst story is invented for fictional companies. A study anchor
later than a screening clock is explicitly retrospective; it is never a current predictor.

A digest without a prior run is a frozen snapshot, not a weekly changes report. Explicit archived
comparison is available at:

`GET /runs/<run>/reports/discovery_digest.md?previous=<earlier-run>`

The prior run must have a strictly earlier aware clock and the same mode. Same-clock policy
comparisons remain available in the run comparison view, but do not receive an interval digest
link. The browser binds the link to the verified comparison response and selected clocks.
Malformed/invalid intervals return 422; invalid archived source evidence returns 503 with no
substituted report. Credential-bearing or nonpublic citation references reject without raw details.

Interval digests retain queue additions/removals, stage changes/invalidation reasons, newly usable
accessions deduplicated by instrument/accession, sector-proxy advancing-theme counts and quality
alerts. Newly represented older/undated filings are not called fresh releases. Source/code/policy
changes warn that differences are not isolated market moves. This is the selected research queue,
not a complete-market filings census, industry-wide breadth estimate, personal browser watchlist
or independently verified thesis-breaker feed. No weekly cadence or forced pick count is inferred.

Legacy reports render available archive fields and disclose missing clocks/profiles. Reports and
underlying archives stay fixture-labeled. No primary-source fact, return, causal story, current
identity, calibration or empirical finding is inferred from a report template.


## Complete validation and adverse-outcome exports

New runs generate `archived-validation-atlas-v1` in `model_validation.md` and
`failed_lookalikes.md`. Validation retains actual periods, policy/cost assumptions, chronological
partitions, saved comparator metrics, constrained turnover/cost ledgers, daily-close risk,
descriptive subgroups, illustrative uncertainty, classification coverage and every stress status.
Unknown ratios stay unavailable. Retrospective evaluation dates can extend beyond the screening
clock and do not become knowable predictors at that clock.

The adverse-outcome atlas preserves nonpositive terminal returns, including round-tripping
maximum-hit winners, and separately lists missing terminal outcomes. Saved case/control assignments,
matching weights and source/code fingerprints remain explicit. No causal reason for divergence is
invented and overlapping horizons do not become independent samples.

Museum and Validation Lab offer these named downloads. The API serves checksum-verified archived
bytes, preserving legacy summaries rather than regenerating them under newer code. Missing saved
reports return 404; corrupt or unverified artifacts return 503. No archive is repaired by reading it.
